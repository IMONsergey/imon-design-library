# Правила сетки

Это локальные рекомендации пака layout-recipes, не общая дизайн-система библиотеки.

## Содержание важнее схемы

- Начните с порядка чтения и смысловых разделов.
- Один главный заголовок страницы; вложенные заголовки отражают структуру, а не нужный размер шрифта.
- Держите описания в разумной длине строки. Для основного текста пак использует ограничение 60ch.
- Не переставляйте смысловые блоки только CSS-свойством `order`: визуальная и клавиатурная последовательности должны совпадать.
- Сетка не требует одинаковой длины текстов. Не скрывайте важное только ради ровных карточек.

## Адаптивность

- Контейнер имеет ограниченную максимальную ширину и адаптивные боковые поля.
- Колонки используют `minmax(0, ...)`, дочерние блоки `min-width: 0`.
- Длинные слова, ссылки и идентификаторы должны переноситься, а не раздвигать страницу.
- Изображениям задавайте размеры, пропорции и подходящий `alt`; декоративным изображениям оставляйте пустой `alt`.
- Кликабельная карточка должна иметь понятное действие. Не используйте ссылку-заглушку и не вкладывайте одну кнопку в другую.

## Чеклист после замены контента

1. Ширины 320, 390, 768 и 1440 px: нет горизонтальной прокрутки страницы.
2. Увеличение текста и масштаба: ничего не перекрывается, кнопки не обрезаются.
3. Самый длинный заголовок и слово без пробелов: сетка не ломается.
4. Клавиатура: порядок перехода совпадает с порядком чтения.
5. Пустое и очень длинное описание: вертикальный ритм остается понятным.
6. Другой пак рядом: стили не меняются без его явного подключения.

Демонстрационные тексты и блоки заменяются содержимым проекта. Шаблон сам по себе не подтверждает доступность конечной страницы.
