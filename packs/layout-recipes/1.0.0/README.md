# Layout recipes / 1.0.0

Оригинальный стартовый пак I’MON с тремя схемами для содержательных страниц. Дает структуру, но не навязывает остальным пакам свою дизайн-систему.

## Подключение

```html
<link rel="stylesheet" href="layout.css">
<section class="imon-layout">
  <div class="iml-container iml-cards">
    <article class="iml-card">Первый материал</article>
    <article class="iml-card">Второй материал</article>
    <article class="iml-card">Третий материал</article>
  </div>
</section>
```

Полные примеры с семантическими заголовками находятся в `templates.html`.

## Схемы

| Класс | Большой экран | Узкий экран |
| --- | --- | --- |
| `.iml-editorial` | Заголовок и описание в пропорции 7/5 | Одна колонка до 760 px |
| `.iml-cards` | Три равные колонки | Две до 760 px, одна до 480 px |
| `.iml-sidebar` | Метаданные и текст в пропорции 1/3 | Одна колонка до 760 px |

`.iml-stack` управляет вертикальным ритмом; `.iml-measure` ограничивает основной текст до 60ch; `.iml-container` ограничивает общую ширину и боковые поля.

```css
.project.imon-layout {
  --imon-layout-max: 1280px;
  --imon-layout-gap: 32px;
}
```

## Ограничения

- Все CSS-селекторы находятся внутри `.imon-layout`, переменные имеют собственный префикс.
- Нет JavaScript, внешних шрифтов, изображений или зависимостей.
- Цветовые прямоугольники и типографика в превью показывают схему. Они не являются фотографиями или готовыми иллюстрациями.
- Для реального контента обязательна проверка на 320 px, масштабировании и длинных заголовках. См. `rules.md`.
- Адаптация под Tilda требует размещения CSS и HTML в целевом блоке и проверки ограничений его контейнера. Автоматического импорта в Zero Block нет.
