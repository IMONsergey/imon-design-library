# Motion essentials / 1.0.0

Оригинальный стартовый набор I’MON: четыре аккуратных CSS-паттерна, а не библиотека эффектов на любой случай.

## Подключение

```html
<link rel="stylesheet" href="motion.css">
<div class="imon-motion">
  <button class="imm-button" type="button">Открыть проект</button>
</div>
```

`patterns.html` содержит разметку остальных примеров. Добавьте собственное действие кнопке и реальные ссылки. Превью намеренно не отправляет данные и не выполняет бизнес-операции.

## Состав

| Паттерн | Длительность | Назначение |
| --- | --- | --- |
| Кнопка | 140 мс | Легкая реакция на наведение и нажатие |
| Стрелка ссылки | 220 мс | Поддержать направление перехода |
| Нативный details | 180 мс | Плавное проявление текста при открытии |
| Появление блока | 420 мс | Один вход без задержки и зацикливания |

Нативный details остается работоспособным без CSS и JavaScript. Открытие и закрытие не имитируются через нестандартный div.

## Изоляция и доступность

Все селекторы ограничены `.imon-motion`, переменные имеют префикс `--imon-motion-`, имена keyframes начинаются с `imon-motion-`. В соседние паки ничего не импортируется.

При `prefers-reduced-motion: reduce` трансформации и анимации отключены. Фокус и цветовая реакция сохраняются. Hover-эффекты ограничены устройствами с точным указателем, поэтому на сенсорном экране нет залипающих состояний.

Перед переносом прочитайте `rules.md`. Системные шрифты, локальные файлы, никаких запросов к CDN. Права описаны в `LICENSE.txt`; публичный доступ не дает свободную лицензию.
