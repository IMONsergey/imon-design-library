# Правила движения

Эти правила принадлежат паку motion-essentials. Они не меняют анимационную систему других паков.

## Сначала смысл

1. Движение подтверждает действие, объясняет изменение состояния или связывает два положения одного объекта.
2. Содержимое и основные действия доступны сразу. Не задерживайте интерфейс ради показа эффекта.
3. Один акцент в один момент. Не анимируйте одновременно всю сетку, заголовки, фон и курсор.
4. Сохраняйте ожидаемое поведение нативных кнопок, ссылок и раскрытий.

## Шкала

- 140 мс: маленькая обратная связь кнопки.
- 180-220 мс: короткое раскрытие или направленная реакция.
- 420 мс: одно появление крупного блока без искусственной задержки.
- Дистанция 1-8 px: достаточна для этих примеров. Большие перемещения требуют отдельного обоснования.

Не ставьте `transition: all`. Перечисляйте свойства. Для геометрии по возможности используйте `transform`; для проявления контента `opacity`. Не добавляйте постоянный `will-change` без измерения.

## Обязательные проверки

- Клавиатура: видимый фокус, Enter/Space работают нативно.
- Сенсорный экран: никакая функция не зависит только от hover.
- Reduced motion: контент остается виден, движение отключается, управление не меняется.
- Без CSS или анимаций: структура и порядок чтения остаются понятными.
- Изоляция: свои keyframes и префиксы, никаких глобальных обработчиков.
- Превью: нет внешних запросов, аналитики, автопроигрывания или скрытых таймеров.

Здесь нет scroll hijacking, изменения системного курсора и бесконечных декоративных циклов. Если они нужны в новом проекте, оформите отдельный пак с собственными ограничениями и тестами.
