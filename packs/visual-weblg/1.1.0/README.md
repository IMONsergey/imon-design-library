# Diamonds Collection

Автор: Сергей Отческов / I’MON. Версия библиотеки: 1.1.0.

Папка: Visual. Внутри 10 самостоятельных HTML-ассетов: круглая, овал, груша, маркиз, кушон, принцесса, изумруд, радиант, ашер и триллион.

Превью коллекции использует первый ассет, `assets/round.html`. У каждой огранки свой файл и свое живое превью. В каталоге они запускаются прямо на странице, без попапа и дополнительной кнопки запуска. Никакого нового демонстрационного контента не добавлено.

## Использование

Открой нужный HTML в браузере. Он работает автономно без интернета, если WebGL доступен.

Для сайта скопируй нужный файл в свой проект, например `diamonds/round.html`:

```html
<iframe
  src="./diamonds/round.html"
  title="Круглая · Diamonds Collection"
  sandbox="allow-scripts"
  width="100%"
  height="640"
  style="display:block;border:0"
></iframe>
```

Для Tilda этот iframe можно поместить в HTML-блок или Zero Block, предварительно разместив HTML-файл на своем сервере. Не вставляй полный документ вместе с его `html/body` стилями прямо в общий DOM сайта. Для нескольких экземпляров используй отдельный iframe на каждый: код, стили и события остаются изолированными.

Пример использует файл целевого проекта, а не обещает разрешенное встраивание публичного превью библиотеки на любой домен.

## Размер и управление

Сцена занимает весь доступный iframe без минимальной высоты 520 px и без внутренней прокрутки. Подходит для карточки 320 × 240 px и для крупного просмотра. Масштаб и ортографическая проекция исходные: камень помещается в область просмотра.

- Перетаскивание мышью или пальцем вращает камень; после отпускания движение плавно затухает.
- Стрелки на клавиатуре меняют ракурс, Home сбрасывает положение.
- На крупном превью доступны кнопки 3/4, сверху и сброс, в том числе на узком экране телефона. В компактных карточках панель скрыта: при высоте до 360 px либо размере до 560 × 440 px.
- Через 2 секунды простоя плавно включается исходный автоповорот. Он вращает камень, а не источники света.
- При `prefers-reduced-motion: reduce` автоповорот и инерция отключаются. Изменение системной настройки учитывается без перезагрузки.

## Нагрузка и жизненный цикл

Малая карточка определяется высотой до 360 px либо размером до 560 × 440 px. В таком режиме длинная сторона canvas ограничена 480 пикселями, DPR не выше 1, отрисовка не чаще 30 кадров/с. Движение рассчитывается по времени, поэтому скорость не зависит от частоты кадров. Для крупного просмотра сохранены исходные коэффициенты качества с адаптивным снижением при медленной отрисовке.

Контекст создан с `preserveDrawingBuffer: true`: готовый кадр сохраняется при простое, reduced motion и повторном захвате изображения. Без этого стандартный backbuffer может очищаться после композитинга, хотя шейдеры и их uniforms остаются валидными. Исправление сохраняет кадр без постоянной перерисовки и не меняет шейдеры. Сохранение буфера имеет дополнительную стоимость по памяти и на некоторых GPU по производительности; ограничение размера карточек и выгрузка невидимых сцен сохраняются. При изменении размера canvas получает статус `pending`, белый фон и затем полный штатный кадр, после которого статус снова `ready`.

Невидимый iframe, скрытая вкладка, удаление компонента и потеря контекста останавливают планирование кадров. После восстановления видимости отрисовка возобновляется; WebGL-контекст восстанавливается с пересозданием ресурсов. При окончательном удалении отключаются события и наблюдатели, освобождаются GPU-ресурсы. При отсутствии WebGL показывается текстовое сообщение вместо бесконечного ожидания.

Производительность зависит от GPU и числа одновременно видимых сцен. Ограничение карточек не гарантирует одинаковую частоту кадров на любом устройстве.
