## Как использовать

Для HTML-блока скопируй содержимое `diamond-cut-study-restored.html` целиком. В одном документе допускается один экземпляр: исходник использует фиксированные `#diamond-cuts-v5` и `#dc5-name`.

Для независимого встраивания скопируй всю папку пака в свой проект как `visual-weblg/`:

```html
<iframe
  src="./visual-weblg/preview/index.html"
  title="Visual WebLG"
  sandbox="allow-scripts"
  width="100%"
  height="780"
  style="border:0"
></iframe>
```

Этот пример использует копию в целевом проекте, а не обещает встраивание публичного превью библиотеки на любой домен. Для просмотра скачанного пака можно открыть `preview/index.html` в браузере.

## Управление

- 10 огранок: круглая, овал, груша, маркиз, кушон, принцесса, изумруд, радиант, ашер и триллион.
- Перетаскивание мышью или пальцем вращает камень, после отпускания сохраняется затухающая инерция.
- Кнопки переключают ракурс 3/4, вид сверху и сбрасывают положение.
- Через 2 секунды простоя плавно включается автоматический поворот. Он возобновляется после завершения ручного движения.
- При системном reduced motion автооборот и инерция отключены; сглаживание управления и переход между огранками остаются. Настройка считывается при загрузке.

## Ограничения исходника

Нужен доступный WebGL с поддержкой используемых шейдеров. Если контекст или компиляция недоступны, исходник показывает «WebGL недоступен». Виртуальные машины, программный рендерер, старые устройства и отключенное аппаратное ускорение могут ограничивать работу.

Минимальная высота компонента 520 px. В узком окне список огранок прокручивается горизонтально. Маленький iframe может иметь внутреннюю вертикальную прокрутку.

Нагрузка зависит от GPU: видимый автоматический поворот продолжает отрисовку. При скрытой вкладке или невидимом компоненте отрисовка пропускается, но callback requestAnimationFrame сохраняется до удаления компонента. Перетаскивание не имеет клавиатурного эквивалента; выбор огранки и ракурса выполняется обычными кнопками. Потеря WebGL-контекста не восстанавливается автоматически.

В каталоге JavaScript запускается только по кнопке внутри изолированного превью. Разрешение `allow-same-origin`, внешняя сеть и доступ к документу каталога не предоставляются.
