# Interface foundation / 1.0.0

Оригинальный стартовый пак I’MON. Небольшая нейтральная база, которую можно взять за основу новой дизайн-системы. Не является стандартом для всех проектов библиотеки.

## Состав

- `tokens.css`: цвета, типографика, интервалы и радиусы.
- `tokens.json`: машинно-читаемая копия базовых значений.
- `components.css`: кнопки, текстовые поля, ошибки и чекбокс.
- `components.html`: примеры разметки.
- `preview/index.html`: полный локальный образец без JavaScript.

## Подключение

```html
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="components.css">
<section class="imon-foundation">
  <button class="imf-button" type="button">Продолжить</button>
</section>
```

Оба CSS-файла подключаются в целевом проекте, не в интерфейсе каталога. Все компоненты находятся внутри `.imon-foundation`. Переопределяйте переменные на этой области, не глобально:

```css
.my-project.imon-foundation {
  --imon-foundation-accent: #303f62;
  --imon-foundation-accent-hover: #263350;
}
```

Кнопки в превью показывают состояния и не выполняют бизнес-действий. Обработка формы, валидация и отправка данных сознательно не входят в CSS-пак.

## Ограничения

- Системный шрифт, никаких загрузок из сети.
- Компоненты не предназначены для подключения прямо в общий DOM другого пака.
- У нескольких полей должны быть уникальные `id`, связанные `label` и `aria-describedby`.
- Контраст нужно проверить повторно после изменения цветов. Границы полей специально темнее декоративных разделителей.
- Анимация ограничена сменой цвета и отключается при `prefers-reduced-motion`.
- `tokens.json` содержит данные, но не обещает прямой импорт во все редакторы токенов.
