# Shared implementation contract v1

No runtime or build dependencies. Node 24. Static app sources are in `site/`; build output is `dist/`.

## Source manifest: packs/<id>/<version>/manifest.json

```json
{
  "schemaVersion": 1,
  "id": "interface-foundation",
  "version": "1.0.0",
  "title": "Interface foundation",
  "summary": "Короткое описание пака.",
  "category": "design-system",
  "status": "published",
  "visibility": "public",
  "tags": ["css", "tokens"],
  "license": {"id": "LicenseRef-IMON-Proprietary", "file": "LICENSE.txt", "redistribution": true},
  "source": {"type": "original", "author": "I’MON"},
  "review": {"by": "I’MON", "date": "2026-11-04"},
  "preview": "preview/index.html",
  "scripts": false,
  "files": ["LICENSE.txt", "README.md", "tokens.css", "preview/index.html"],
  "assets": [{"id": "tokens", "title": "Токены", "type": "tokens", "path": "tokens.css", "description": "Токены с собственным префиксом.", "usage": "Подключите tokens.css только в целевом проекте."}]
}
```

- `id` and asset ids are lowercase ASCII slugs, versions are strict numeric `major.minor.patch` without leading zeros.
- Categories: `design-system`, `components`, `motion`, `icons`, `typography`, `guidelines`, `templates`.
- Status: `draft` or `published`; visibility: `public` or `private`. Only public+published is built. Source git must not contain private material even if a manifest is private.
- Asset types: `component`, `stylesheet`, `script`, `tokens`, `documentation`, `image`, `font`, `template`.
- Files are explicit, regular non-symlink paths within the pack. All preview resources must be explicitly listed. No parent traversal, absolute paths, URL paths, dotfiles, credentials or executables.
- `source.url` is optional HTTPS provenance, not an import dependency. Third-party sources require URL and explicit permission through `license.redistribution`.
- Original starter packs remain proprietary I’MON material. The project does not grant an open-source license on the owner's behalf.
- All published packs require a source, license file, explicit redistribution=true, review, preview HTML and at least one asset. The build never executes asset code.
- All export URLs are generated by the builder, not supplied by manifests.

## Generated /api/catalog.json

```json
{
  "schemaVersion": 1,
  "packs": [{
    "id": "interface-foundation", "version": "1.0.0", "title": "Interface foundation", "summary": "...",
    "category": "design-system", "tags": ["css"], "license": {"id": "LicenseRef-IMON-Proprietary", "redistribution": true},
    "source": {"type": "original", "author": "I’MON"}, "review": {"by": "I’MON", "date": "2026-11-04"},
    "previewUrl": "/previews/interface-foundation/1.0.0/preview/index.html", "scripts": false,
    "downloadUrl": "/downloads/interface-foundation-1.0.0.zip", "manifestUrl": "/api/packs/interface-foundation/1.0.0.json",
    "files": [{"path": "tokens.css", "url": "/raw/interface-foundation/1.0.0/tokens.css", "size": 123, "sha256": "..."}],
    "assets": [{"id": "tokens", "title": "Токены", "type": "tokens", "path": "tokens.css", "description": "...", "usage": "..."}]
  }]
}
```

The builder publishes allowlisted files to `/raw/<id>/<version>/` for reading/downloading and `/previews/<id>/<version>/` for isolated rendering. Raw files must be served as plain text or attachments, never executable HTML. Previews get HTTP CSP sandbox with no same-origin permission, blocked network, form actions, popups and framing of other pages. Catalog iframes also have sandbox (empty or only `allow-scripts` when scripts=true). Never give `allow-same-origin`.

The app fetches `/api/catalog.json`; show latest version per id by default, expose exact version selector and a stable hash `#pack=<id>@<version>`. Metadata is rendered with textContent. Search combines title, summary, tags and asset descriptions. No user upload endpoints or writable server API in v1.
